# Lunelle 安装手账

六页自定义安装界面：欢迎、完整许可、当前用户范围、安装位置、真实安装阶段、完成与启动。透明窗口使用曲线纸边及同形交互区域；每页使用独立人物姿态。

v0.3.23 按批准的六页设计重做插画纸张与人物，移除欢迎说明卡；许可正文改为中文。纸面空白处可拖动窗口，按钮、输入和许可滚动区独立接收操作，其他文字不可误选。安装进度表示真实引擎运行状态，不显示模拟百分比。

```sh
npm run build -- --with-artwork
npm run installer
npm run installer:preview
npm run test:installer
node scripts/test-installer-engine.cjs
```

`installer` 先构建 electron-builder NSIS 引擎，再封装带本地 Electron 运行时的六页界面，最终输出 `installers/Lunelle-Setup-0.3.25-x64.exe`。启动仅解压界面及其使用的字体；点击安装后再按需解压引擎，准备过程显示在进度页。无需联网安装或另装运行时。

界面运行时按版本与内容标识缓存于 `%LOCALAPPDATA%/LunelleSetupCache`，再次打开相同安装包时复用，避免重复解压。缓存不包含账号数据或桌宠偏好；按需提取的引擎在正常关闭安装器时移除。首次打开仍需准备界面运行时，耗时受磁盘与系统扫描影响。

安装仅支持当前用户。路径必须是有效本地文件夹，不能指向磁盘根目录、Windows 系统目录或已有其他内容的目录。升级应选择原目录。卸载注册与偏好保留由原安装引擎负责。

进度条表示引擎仍在运行，不伪造百分比。写入期间关闭入口会说明需等待完成，以免强制中断导致文件不完整；引擎错误会回到位置页，保留选择并给出重试信息。

界面测试不会执行安装。引擎集成测试使用独立的应用 ID、可执行文件和快捷方式名称，验证中文及空格路径、升级、文件一致性和卸载。

人物素材来自内置 image_gen：以原桌宠坐姿为身份及质感参考，六页设计稿为姿态参考。共同提示约束为 3×2 独立完整角色、透明背景、统一服装与比例；依次挥手、阅读、示意、指路、闭眼等待、站姿招手。后续以原桌宠为参考减弱硬高光和金属感，再按固定网格导出六张 PNG；未替换桌宠本身素材。素材权利见项目 ASSETS.md。
