# 08 · 面板陪伴

设计参考：`assets/characters/idle-seated.png`、`portrait-perch.png`、`docs/images/quota-panel-restored-hd.png`。

设计图由内置图像生成工具制作。提示方向：保持角色原有柔和淡彩质感，双手搭住纸边；展示进入约 0.4 秒、持续呼吸、偶尔歪头和退出约 0.35 秒的状态。实际实现使用原有趴边立绘连续形变，手部权重归零，避免重绘造成质感跳变。当前实现包含呼吸、歪头和淡入淡出，未加入独立眨眼素材。

入口：宠物右键、托盘或设置中的「08 · 面板陪伴」。单击宠物只互动；收起使用纸边 ×、Esc 或点击面板外。陪伴期间暂停散步，按住趴边人物可拖动位置。
