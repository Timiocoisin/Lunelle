# Lunelle v0.3.32 · 同一个她，两个年纪

- 设置中可切换经典淡紫少女与成年暗月女王，并自动保存。
- 两种形态均支持呼吸、眨眼、歪头、点头、挥手、拖放落地、附近散步与面板陪伴。
- 两种形态沿用 72 帧、1.44 秒的行走节奏；少女使用侧面外观、独立左右手、朝前的鞋向与稳定近远腿间距。
- 平滑少女行走的躯干起伏，以膝盖弯曲吸收支撑脚切换的高度差，保持原来的脚踝轨迹。
- 成年形态行走材质与坐姿统一。
- README 使用全新首屏、双形态画册、两套完整动作实图及高清无损行走展示；两种手账与完整设置页均可查看高清图。
- 六页自定义安装手账，支持覆盖升级并保留偏好设置。

## 下载与校验

下载本页附件 `Lunelle-Setup-0.3.32-x64.exe`，并使用 `SHA256SUMS-v0.3.32.txt` 校验。

需要 Windows x64。安装包自带运行时，无需另外安装 Node.js；读取额度需要已安装并登录 Codex。代码采用 MIT 许可，角色与图像素材权利见 ASSETS.md。安装包尚未配置代码签名。
