# Lunelle 0.3.0 动作与活动

## 八组动作

| 动作 | 实现 | 触发 |
| --- | --- | --- |
| 待机呼吸 | 人物内部图层轻微伸缩与上下起伏，卷发轻摆 | 待机 |
| 眨眼 | 闭眼姿态短暂切换，约 150ms | 面板关闭时随机间隔 4～8 秒 |
| 歪头 | 人物图层小角度偏转后复位 | 随机点击反馈 |
| 点头 | 两次轻微下点后复位 | 随机点击反馈 |
| 挥手 | 挥手姿态与轻微摆动 | 随机点击反馈 |
| 拖动与落地 | 越过拖动阈值后切换拎起姿态，松手后回弹 | 手动拖动 |
| 散步 | 完整身体与左右腿图层连续错相摆动，并改变屏幕位置 | 自动活动：全屏散步 |
| 面板陪伴 | 停止散步与自主动作，仅保留轻微呼吸 | 面板展开 |

位置、朝向、呼吸和动作使用不同图层，人物动作不会改变按钮的点击区域。
点击仍只切换一次面板，点击反馈结束后恢复待机或陪伴。

## 自动活动

- 默认关闭，在“设置 → 交互与说明”开启。
- 原地活动：保持位置，空闲后看看四周。
- 全屏散步：目标可在当前显示器整个工作区内，不限制在手动放置点附近。
- 空闲等待随机 30～60 秒；速度约 40～58 DIP/秒；抵达后看看四周。
- 鼠标距离角色矩形小于 100 DIP、开始拖动、打开面板或设置、隐藏桌宠都会中断自动活动。
- 中断后重新等待，不恢复过期的目的地；自动散步不越界、不跨显示器。
- 自动活动不调用位置保存。只有实际手动拖动才保存，点击不会把临时散步位置写入设置。
- 动作预览位于同一设置页，只演示姿态，不移动桌宠或展开面板。

## 优先级

拖动 > 面板与设置操作 > 点击反馈 > 自动活动。
面板打开可以显示一次点击反馈，随后只保留陪伴呼吸；停止眨眼与自主歪头。
关闭面板、结束拖动或关闭设置后，自动活动重新等待空闲时段。
系统减少动态效果偏好会禁用非必要的位移、缩放与旋转动画。

## 验证

- 单元测试覆盖默认值、中断条件、全屏目标、边界以及位置不持久化。
- 界面测试逐个触发八组动作，核对点击区域不变、面板互斥、真实拖动姿态与落地反馈。
- 保留坐标方向、逐帧位移、设置持久化与数据读取等原有回归检查。

## 0.2.1 调整

- 待机恢复原始 `pet.png`，眨眼按原图制作；只给次要动作姿态添加柔和色彩校正。
- 设置页显示活动关闭、面板/设置暂停、鼠标靠近或剩余等待时间。
- “开启全屏散步并立即试走”会关闭设置、收起面板，3 秒后尝试走动；鼠标靠近时等待移开。
- 相同的面板关闭状态报告不会重置试走倒计时。

## 0.2.2 连续步态

- 移除两张完整步态图按定时器轮播的做法。走路使用同一张纹理划分身体、左腿与右腿，双腿用连续变换错相摆动，身体不换图。
- 自动散步位置更新提高到约 60Hz，并使用短线性过渡衔接；手动拖动仍直接跟随。
- 取消按屏幕左右半区和行走方向自动镜像角色，保持原始朝向。
- 原图待机、面板锁定、鼠标靠近暂停与手动位置保存规则不变。

## 0.2.3 完整腿部与不激活窗口

- 使用重新绘制的完整左右腿，保留裙摆下的大腿重叠部分，移除关节裁切遮罩。
- 1100ms 步态周期包含摆动抬脚、接触落地和支撑后移；双腿前后位置与遮挡顺序交换。
- 桌宠和额度面板固定置顶、不可聚焦；只对自身窗口处理 WM_MOUSEACTIVATE 并返回 MA_NOACTIVATE，保留前台应用同时不吞单击。
- 仅用户主动打开的独立设置窗口获取键盘输入焦点。显示/隐藏或第二实例唤起不激活桌宠。
- 可见时定期用不激活方式保持桌面层级；设置窗口打开时暂停层级维护。
