# Lunelle · 动作与播放

本文对应 v0.3.32。经典萝莉与御姐是同一个 Lunelle 的不同年龄形态，分别保留服装、配饰和身体比例。两种形态均以侧面散步，共用 72 帧、1.44 秒的步态与移动时间轴。

## 交互规则

自动活动默认开启。空闲约 15–25 秒后，在当前显示器工作区内散步一趟，约 8–15 秒；不自动跨屏，也不覆盖手动保存的位置。鼠标经过继续散步，点击、拖动、展开手账、打开设置或隐藏桌宠会停止或暂停活动。

左键随机触发动作 01–05，避免连续重复；拖动触发动作 06，松手回坐；右键直接进入动作 08。设置中的八个动作按钮可逐项预览。动画不会改变点击区域，拖动位置与角色画面使用同一显示坐标。

## 八类动作

| 动作 | 经典萝莉 | 御姐成年形态 |
| :--- | :--- | :--- |
| 01 呼吸 | 抱星星坐姿轻微呼吸 | 月牙座坐姿轻微呼吸 |
| 02 眨眼 | 原坐姿的局部眼皮变化 | 原坐姿的局部闭眼贴图 |
| 03 歪头 | 头肩连续倾斜后回正 | 连续表面上的头部倾斜 |
| 04 点头 | 下俯并配合闭眼 | 下俯并配合闭眼 |
| 05 挥手 | 坐姿局部肩臂摆动 | 专用挥手坐姿与局部手臂摆动 |
| 06 拖动与落地 | 抱膝悬空，松手缓冲回坐 | 专用悬空及落地姿态 |
| 07 散步 | 放下抱枕，以侧脸、侧身行走 | 暗月长裙侧面行走 |
| 08 面板陪伴 | 双手搭在纸边，轻微呼吸及看向 | 专用月牙座坐姿，安静陪伴 |

刷新成功时，陪伴人物点头回应。读取失败保留上次数据并标记状态。面板展开后停止散步；纸边 ×、Esc 或点击面板外收起，移开鼠标不会自动关闭。

## 统一侧面步态

两种形态使用相同的腿部方向、肩部和摆臂角度，并按各自身体比例重定向骨骼长度。角色朝右时采用原图，朝左时镜像完整画面。经典形态先统一缩放，再镜像，以确保左右像素对应；换向不重置步态相位。

萝莉行走采用单眼可见的侧脸、窄侧身、侧向裙摆和朝向一致的月亮鞋。近侧右手与远侧左手分别使用独立的侧面贴图，由身体和头发自然遮挡。头皮、刘海和呆毛只属于主体层；后方长卷发作为连续整体跟随，避免重复头发或分段折叠。

动作从已经校对的 CMU07_04 慢步周期重定向。生成阶段将各层绘制成完整透明画面；应用运行时只播放完整帧，不在线生成图像，也不重新拼接关节。

| 经典萝莉侧面行走 | `assets/characters/classic/shared-walk/walk.webp` | 72 帧，20ms/帧，1.44 秒 |

真实散步根据显示位置增量推进时间轴，停止移动时保持当前相位；设置预览按时间播放。减少动态效果时固定首帧。ImageDecoder 本地解码使用有界缓存：经典形态最多八帧，成年形态最多六帧。

旧版 `walk-v19` 抱枕散步素材保留为历史资料，不再是当前经典形态的运行资源。

## 衔接与验证

左键回应先留出约 220ms 停稳缓冲；新点击、拖动或陪伴会取消待播回应。互动或落地完成后重新计时，散步后回到坐姿。

`npm test` 检查时间轴、两种形态的相位一致性、素材摘要、帧数与时长、手掌比例及独立左右手资源。`npm run test:ui` 检查 Electron 解码、透明背景、左右镜像、缓存、设置切换、八类动作和拖动位置。

当前侧面素材与源关节锚点位于 `docs/design/classic-side-walk/`，公用运动数据为 `docs/design/shared-walk-cycle.npz`。由 `scripts/export-classic-shared-walk.py` 导出经典行走；`scripts/export-queen-walk.py` 导出成年形态。素材权利与生成记录见 [ASSETS.md](../ASSETS.md)。

经典行走素材 v23：保留 v22 的侧面鞋向和近远腿间距，对接地计算产生的躯干高度使用循环平滑，并降低起伏幅度。脚踝沿用原来的轨迹，膝盖通过固定弯曲方向的两段骨骼求解吸收高度差；共用换腿节奏和 1.44 秒时长保持不变。README 的双形态动图由当前运行素材重新导出。
